# OctoAcme Project Management Docs

This repository centralizes the core project management guidance used by OctoAcme. It provides a lightweight, searchable set of process documents to help teams initiate projects, plan delivery, execute work, manage risk, and improve over time.

## Project management processes summary

OctoAcme uses a cross-functional project lifecycle that includes:

- Initiation: confirm the problem, goals, stakeholders, and go/no-go decision.
- Planning: define scope, backlog, milestones, risks, and delivery responsibilities.
- Execution: track work in progress, run standups, manage blockers, and maintain quality through review and testing.
- Release & deployment: validate readiness, prepare release notes, and manage rollout and rollback plans.
- Retrospective & continuous improvement: capture learnings, track action items, and improve the process over time.

## How to use this docs set

Use the overview and initiation guides to start a project, the planning guide to structure work, the execution and risk docs to manage delivery, and the release and retrospective guides to close the loop on outcomes and learning.
